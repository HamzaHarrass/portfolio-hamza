## 🎨 Design Philosophy
The portfolio is built with a **Premium Dark Aesthetic**, utilizing:
- **Typography**: A curated mix of *Bebas Neue* (Impact), *Cormorant Garamond* (Elegance), and *DM Mono* (Technical).
- **Interactivity**: Custom-engineered cursor tracking, grain-texture overlays, and smooth reveal animations.
- **Visuals**: Glassmorphism, animated gradients, and grid-based layouts to convey a technical yet sophisticated brand.

## 🚀 Core Features
- **Responsive Design**: Fluid layouts optimized for all screen sizes using Tailwind CSS.
- **Interactive Terminal**: A custom-built terminal component reflecting developer skills and background.
- **Project Case Studies**: Deep dives into technical challenges, such as the **ZeTheta SAP Integration**.
- **Performance Optimized**: Lazy loading, optimized font delivery, and minimal asset overhead.
- **SEO Ready**: Fully implemented Meta, Open Graph, and Twitter tags for professional social sharing.

## 🛠️ Technology Stack
- **Frontend**: HTML5, Tailwind CSS (Custom Config), Vanilla JavaScript.
- **Animations**: CSS3 Keyframes & Intersection Observer API.
- **Case Study Tech Focus**:
  - **Runtime**: Node.js, TypeScript.
  - **Backend**: Express, Supabase.
  - **Resilience**: Opossum Circuit Breaker.
  - **Validation & Testing**: Zod, Jest.

## 📂 Project Highlights

### ZeTheta SAP Integration
An enterprise-grade synchronization engine bridging legacy ERP systems with modern analytics.
- **Clean Architecture**: Decoupled source/destination logic.
- **Observability**: Structured Pino logging and Appendix J error registry.
- **Resilience**: Dead Letter Queues (DLQ) and automated checksum reconciliation.

## ⚙️ Development & Setup

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```
2. **Open the project**:
   Simply open `index.html` in your browser, or use a Live Server extension (e.g., in VS Code).

3. **Customization**:
   Tailwind is configured via a script tag in `index.html`. You can modify the `tailwind.config` object to adjust colors and fonts.
